# Ball website

The public website of **Ball**, the one-tap physics puzzle game for iPhone and Mac: https://ea7600.github.io/playball.io/

Download Ball on the App Store: https://apps.apple.com/app/id6834097033

- `/`: about the game, with the App Store link
- `/privacy.html`: privacy policy
- `/support.html`: support
- `/feed.json`: news and gifts the apps read

`/site/` forwards to the home page (it was the page's old address). The files here are generated; the game is developed in a private repo.
